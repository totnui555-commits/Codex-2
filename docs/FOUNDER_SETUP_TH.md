# สถานะการเชื่อมต่อและสิ่งที่เหลือ

- GitHub: ใช้ตัวตนที่เชื่อมต่ออยู่ เขียนได้เฉพาะ repository ส่วนตัวที่ระบบกำหนดคือ totnui555-commits/Codex-2 ไม่คัดลอก token ลง .env
- กำหนดราคาวิจัย/โมเดล Codex จากแค็ตตาล็อก OpenRouter และ FX จาก Frankfurter วันที่ 2026-10-19
- เก็บรายงานแบบเข้ารหัสถาวรใน workspace จริง; ไม่อ้างว่าเป็น cloud S3
- เพดานทดสอบ 100 บาท, พร้อมกันไม่เกินหนึ่งงาน และปิด paid execution กลับหลังการตรวจสอบ
- เตรียมตัวเลือก Codex ผ่าน OpenRouter ตามคู่มือทางการ จึงยังไม่จำเป็นต้องสมัคร OpenAI เพิ่มเพื่อการตั้งค่าตอนนี้; ความเข้ากันได้กับ Codex SDK ใน hosted sandbox ยังต้องทดสอบจริง

## สิ่งที่ต้องใช้บัญชีของเจ้าของ
1. เข้าสู่ระบบ/สมัคร Daytona ที่ https://app.daytona.io และสร้าง API key สำหรับ workspace ที่ต้องการใช้ ต้องยอมรับเงื่อนไข/การเรียกเก็บเงินด้วยตนเองหากบริการกำหนด จากนั้นเพิ่ม DAYTONA_API_KEY ผ่าน secure environment configuration
2. การรัน sandbox จากภายนอกต้องเข้าถึง HTTPS model gateway ได้ การนำขึ้นโฮสต์ต้องมีบัญชี/โดเมนหรือช่องทาง private networking ที่คุณอนุญาต ไม่มีการสร้าง public tunnel หรือเปิดเผยแอปโดยอัตโนมัติ

เมื่อมี key และที่อยู่ gateway แล้ว ผู้ดำเนินการสามารถตรวจสิทธิ์/ราคา สร้าง snapshot และรัน benchmark ต่อได้ โดยยังต้องอยู่ในงบที่อนุญาต ไม่มีการอ้างว่าสร้าง hosted sandbox สำเร็จแล้ว

Gmail OAuth ของแอป, cloud S3 และ payment onboarding ใช้ในขั้น production/การค้า ไม่ต้องเปิดทั้งหมดเพื่อทดลองอ่านรายงานในระบบตอนนี้ บัญชี Gmail ที่เชื่อมกับแชตไม่ใช่ OAuth credential ที่ย้ายเข้าแอปได้

## อัปเดตหลังอนุญาตให้ดำเนินการต่อ
ได้รับสิทธิ์ดำเนินงานต่อแล้ว ไม่ต้องอนุญาตซ้ำแบบครอบคลุม ตรวจการเชื่อมต่อแล้วพบ Render เป็นทางเลือกสำหรับโฮสต์ HTTPS gateway แต่ยังไม่ติดตั้ง/เชื่อมบัญชี จึงยัง deploy ไม่ได้ ข้อมูลบัญชี Daytona ยังไม่ปรากฏใน environment เช่นกัน

ระหว่างรอการเชื่อมบัญชี ได้เพิ่ม Product Incubator ที่ใช้งานจริงพร้อมทดสอบฐานข้อมูล/เบราว์เซอร์แล้ว โอกาสหนึ่งรายการเชื่อมเป็น backlog และร่างทดลอง จำนวนตัวอย่างยังเป็นศูนย์ ไม่มีการอ้างลูกค้าหรือยอดขาย และไม่มีค่าใช้จ่ายโมเดลเพิ่มในรอบนี้

# ADR-KINGDOM-3D: additive flagship island world

Accepted 2026-10-20. The founder explicitly requested keeping the existing Office and adding Kingdom Edition. The supplied v2 specification describes the new edition; its cancellation language does not override the founder's direct preservation request. Kingdom becomes the default landing view; Office remains an independent legacy route. No office floors or tower geometry appear in Kingdom.

Preserve FastAPI, PostgreSQL/RLS, Temporal, audit/events, owner authorization, budgets, workers and provider adapters. Render a versioned original Blender-authored island/landmark kit through R3F/Drei. Static art, deterministic navigation and read-only domain projections are separate modules. No backend change or paid integration is required for visual navigation.

Stable citizen identity derives from organization + persisted agent role ID, never display name or array order. A deterministic visual profile is a presentation mapping, not a claim of a running agent process. Actual tasks/runs determine execution status, target landmark, evidence and animation. Local footsteps and breathing are cosmetic. No work, incident, delivery or revenue is generated by animation. Reconnect continues using the existing authenticated snapshot/event flow. Missing/stale connection is labeled.

Landmarks link to existing real dashboards and inspectors, not duplicate mock APIs. Lighthouse severity derives only from open incidents and reports independent monitor heartbeat separately. Safe controls remain authenticated existing backend operations. World components have no provider credentials or spending authority.

Acceptance: original coastline, water, keep, separate village buildings, harbor, boats and ridge lighthouse; functional landmark/citizen selection; camera presets/follow/reset; low/balanced/high and reduced motion; accessible list fallback; stable role identities and authoritative state tests; real browser desktop/mobile/reconnect/Office preservation, screenshots and measured rendering observations. Blender sources and GLB exports are versioned and reproducible. This milestone does not resolve external hosted coding/deployment credentials or certify the full company production-ready.
